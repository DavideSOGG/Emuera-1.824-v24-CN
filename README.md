# Emuera 1.824+v24 日文原版独立备份

本仓库的 `original-backup` 分支是使用 **orphan branch** 建立的独立备份分支，仅用于长期保存 Emuera 1.824+v24 日文版参考文件。

## 分支说明

- 本分支拥有独立提交历史，与 `main` 分支的汉化修正源码不共享父提交。
- 本分支不包含简体中文汉化源码，也不参与汉化版本构建。
- 汉化开发、问题修复和发行版本均位于 `main` 分支。
- 需要核对日文原文、默认日文文本或原始实现时，请切换至本分支。
- 本分支不应合并到 `main`，也不要将汉化提交合并进本分支。

## 文件说明

- `Emuera1824+v24.exe`：日文版 Emuera 1.824+v24 可执行文件，按原样保存。
- `src1824+v24-jp-source.7z`：日文版源码压缩包，按原样保存。内部包含 C# 源码、解决方案、资源和原始许可证。
- `Emuera_readme.txt`：Emuera 基础版原始日文说明。
- `私家改造版Emuera_readme.txt`：1.824+v24 私家改造版的修改说明和版本历史。
- `LICENSE` / `license.txt`：原版 Emuera zlib/libpng 许可证。
- `SHA256SUMS.txt`：所有原始备份文件和许可证的 SHA-256 校验值。

## 来源与版本

- 基础程序：Emuera 1.824
- 日文参考版本：Emuera 1.824+v24 私家改造版
- 原始文件日期：2024-11-06
- 原始源码压缩包保留 `src1824` 目录结构，压缩包本身未重新打包或修改。
- 该版本是在原始 Emuera 基础上包含兼容性和错误修正的私家改造版，并非本仓库制作的简体中文版本。

## 完整性校验

在仓库根目录运行以下命令可核对文件：

```powershell
Get-FileHash .\Emuera1824+v24.exe -Algorithm SHA256
Get-FileHash .\src1824+v24-jp-source.7z -Algorithm SHA256
```

也可将 `SHA256SUMS.txt` 中各文件的校验值与对应文件逐一比较。
